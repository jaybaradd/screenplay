# Live end-to-end test screenplay

`the_debt_at_noon.txt` is an original contemporary screenplay created specifically for testing this application. Its dramatic premise is derived from Anton Chekhov's one-act comedy *The Bear* (1888): a grieving widow is confronted by an urgent creditor, their dispute exposes both of their vulnerabilities, and hostility gives way to reluctant recognition.

The screenplay does not copy dialogue from an English translation. It uses newly written dialogue, contemporary circumstances and an altered resolution so it can function as a neutral adaptation input.

Public-domain source reference: [Project Gutenberg, *Plays by Anton Chekhov, Second Series*](https://www.gutenberg.org/ebooks/7986), which includes *The Bear* and identifies the volume as public domain in the United States.

## Test profile

- Four scenes
- Four speaking characters: Mara, Dev, Viktor and Ina
- Contemporary rural farm setting without a specified country or regional culture
- Explicit character entrances, recurring props and custody changes
- Debt, grief, trust and reluctant-respect emotional arcs
- Trackable envelope, delivery log, brass key, pistol case, tea tray and vehicle continuity
- Visual changes across rain, power loss and clearing weather
